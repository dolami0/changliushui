# 产业链利润流分析工作流

> **类型**: 独立工作流（LLM × 2 + Volc 搜索 + Tushare 数据）
> **文件**: `src/industry_chain_workflow.py` (1594 行)
> **触发**: 产业资讯事件发生时独立触发

---

## 管线架构

```
Step 1a: 轻量预搜索 (2次Volc并行)
  ├── Q1: 产业链结构与利润截留
  └── Q2: TAM与进入壁垒

Step 1b: LLM #1 粗判节点 (Flash)
  └── 识别产业链节点 → 输出 top_two 节点

Step 1c: 定向深搜 (每节点1次Volc，全节点并行)
  └── 利润分配 + 竞争格局 + 技术壁垒 + TAM

Step 2: LLM #1 精析 (Flash, tool-use: fetch_url ≤2次)
  └── 5 维利润截留评估 → 输出 top_two_nodes 详情

Step 3: Volc 节点搜索 (2次并行)
  └── 每节点搜索 A 股公司列表 (市值 20-300 亿)

Step 4: LLM #2 提名 (Flash)
  └── 每节点提名 5 只候选股 (仅名称，不含代码)

Step 4.5: Tushare 代码校验
  └── 4 级名称匹配 → 真实代码

Step 5: 数据富化 (Tushare 批量 + Volc 个股并行)
  └── 市值/PE/财务指标 + 个股投资地图

Step 6: LLM #2 评分 (Pro, tool-use: bocha ≤1次)
  ├── 四维评分 (影响×0.45 + V3匹配×0.25 + 叙事×0.20 + 稀缺×0.10)
  ├── 黑洞/弹射判定 (低市值的两种命运)
  ├── TAM 校验 (5x 终点能在多大市场装下？)
  └── best ≥ 6.5 → 输出; best < 6.5 → Pass 2 节点2候选股
```

## LLM #1: 产业链利润流分析师

### 两阶段设计

**阶段 1 — 粗判** (Flash):

```json
{
  "model": "deepseek-v4-flash",
  "max_tokens": 8192,
  "temperature": 0.0
}
```

输入: 轻搜结果（2 次 Volc 并行搜索的结构化报告）
输出: `{"industry": "", "all_nodes": [...], "top_two": [...]}`

禁止事项: 禁止提及具体上市公司名称、禁止引用市值/PE/股价

**阶段 2 — 精析** (Flash, tool-use):

```json
{
  "model": "deepseek-v4-flash",
  "max_tokens": 30720,
  "temperature": 0.0,
  "thinking": {"type": "enabled"}
}
```

工具: `fetch_url` 最多 2 个 URL（仅用于读取摘要不足的全文）

输入: 轻搜结果 + 所有节点定向深搜结果
输出: 完整产业链分析 JSON

### 五维利润截留评估

| 维度 | 评估内容 |
|------|---------|
| 议价能力 | 对上游能否压价？对下游能否提价？ |
| 集中度 | 寡头还是散兵？CR3/CR5 |
| 转换成本 | 认证周期/产线绑定/监管壁垒 |
| 增值比例 | 该节点贡献最终产品价值的百分比 |
| 需求弹性 | 事件直接拉动还是间接蹭到？ |

### 隐性上游优先原则

产业链利润往往向"隐性上游"集中——体积小、价值密度高、认证壁垒极强的上游环节（芯片、特种材料、核心元器件），而非显眼的中游总装。

- 若某上游环节占下游成品成本 <5% 但断供即瘫痪 → 利润截留极高
- 中游总装即使产值大，若竞争分散、切换成本低，利润截留反而不如隐性上游
- 不无限向上游追溯：只考虑一阶直接供应商

### 利润截留评分 (1-100)

| 分数 | 含义 |
|------|------|
| 90-100 | 绝对龙头节点（市占>50%+毛利率>30%+切换成本极高） |
| 70-89 | 强截留节点（寡头格局+高壁垒+高增值占比） |
| 50-69 | 中等截留节点 |
| 30-49 | 弱截留节点 |
| 1-29 | 几乎不截留 |

## LLM #2: 十倍股赔率评估师

### 提名阶段 (Flash)

```json
{
  "model": "deepseek-v4-flash",
  "max_tokens": 8192,
  "temperature": 0.0
}
```

为指定产业链节点找出 5 只最相关的 A 股候选。优先从 Volc 搜索结果提取，不足 5 只时用 A 股知识补足。不需填代码。

### 评分阶段 (Pro, tool-use ≤2 turns)

```json
{
  "model": "deepseek-v4-pro",
  "max_tokens": 30720,
  "temperature": 0.0,
  "thinking": {"type": "enabled"},
  "reasoning_effort": "high"
}
```

工具: `bocha_search` + `fetch_url`，最多搜索 1 次（仅补充定性信息）

### 评分维度 (1-10 分)

**硬过滤**: 市值 > 300 亿 → 直接剔除，不进入评分

**1. 事件冲击比 (45%)**: 暴露度 × 赔率杠杆

前置判定: 低市值是"弹射"还是"黑洞"？

黑洞信号（出现任一 → impact ≤ 5）:
- 毛利率 < 15%
- 资产负债率 > 70% 且净利率 < -30%
- 营业利润亏损额 > 营收的 50%
- 营收同比持续下滑

弹射信号:
- 毛利率 > 25%，亏损来自研发/扩张投入
- 资产负债率 < 60%
- 营收同比转正或环比改善

**2. V3 模式匹配 (25%)**:
- 10 = 亏损反转型（寒武纪型）
- 7 = 隐形冠军型（九安型）
- 4 = 加速成长型（中际型）
- 1 = 周期 β 型（协创型）

**3. 叙事亮点 (20%)**: 独特性/稀缺性 + 催化剂具体性 + 预期差 + 验证路径

**4. 唯一性溢价 (10%)**: 按可触及的细分市场竞争格局

### 总分计算

```
总分 = impact×0.45 + v3match×0.25 + narrative×0.20 + scarcity×0.10
```

### 阈值硬规则

候选股 total_score 均 < 6.5 → top_pick = "无高赔率标的"。禁止虚高打分凑数。

## Volc 搜索配置

```json
{
  "endpoint": "https://open.feedcoopapi.com/agent_api/agent/chat/completion",
  "bot_id": "7640524154441156122",
  "auth": "Bearer {VOLC_AGENT_KEY}",
  "timeout": 60-90
}
```

### 三种搜索模式

| 模式 | 并行度 | 每次查询内容 |
|------|--------|------------|
| 轻搜 | 2 并行 | Q1: 产业链结构+利润截留 / Q2: TAM+进入壁垒 |
| 深搜 | 每节点 1 次，全节点并行 | 利润分配+竞争格局+技术壁垒+TAM |
| 个股搜索 | 3 并行（仅 ≤300 亿市值） | 主营匹配/竞争壁垒/近期催化/差异化 |
