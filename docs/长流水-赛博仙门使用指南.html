零、这是个什么东西

长流水是一个用 AI 挖十倍股的系统。它每天自动监听 A 股重大事件——政策、涨价、技术突破、订单放量——然后分析：这个事件能不能让某只股票大涨？

全流程自动。你的角色是裁决者：看结果、做判断、下决策。

一、首页（全景监控面板）

打开网站看到的第一屏。这个页面让你一望而知系统的运转状态、最新的猎物、以及你正在追踪的标的。

1.1 风闻入阵

首页顶部区域，快速提交一条市场消息或小道消息。粘贴资讯原文，系统自动归类、评分、匹配受益个股。消息入阵后进入估值管线排队，过段时间就能在定数录里看到分析结果。
📌 怎么用：看到有价值的资讯→粘贴进去→传讯入阵。不用自己去手动匹配标的，系统自动找。

1.2 定数录

估值报告的汇总面板。每一条都是系统跑完的完整估值报告——显示标的名称、事件概要、加权涨跌幅、不对称比、通过状态。相当于你的「猎物清单」。
📌 怎么用：按加权涨跌幅排序，先看涨幅最高的。点击跳转到详细估值报告。点击「藏经云→定数录」可进入全量表格视图，支持搜索和排序。

1.3 天眼司

事件监听的状态面板。展示当前正在监听的事件源、响应等级、匹配到的标的数。一眼知道系统有没有在正常工作。
📌 怎么用：确认监听中（绿色指示灯）。如果停了，去总控台开启调度器。

1.4 跟踪令

已通过审阅的标的快捷监控面板。列出所有追踪中标的的核心指标：当前价格、涨跌幅、PE、论点状态。
📌 怎么用：扫一眼——有没有标红的（论点 at_risk 或 broken）？点击进入完整的追踪令详情页。

核心原则：不要只看加权涨跌幅就追。先看 Bear——最差亏多少？再看不对称比——值不值得冒这个险？最后想——这个故事你自己信不信？

报告中常见术语

术语一句话
估值锚市场在用利润(PE)、收入(PS)还是资产(PB)给这家公司标价。锚不同，逻辑完全不同。
Bear / Base / Bull故事没成 / 故事正常推进 / 故事超出预期——三种情况下的市值和涨跌幅。
不对称比Bull 赚的 ÷ Bear 亏的（加权后）。>1.5x 才划算。
置信度系统给自己的报告打分（信息质量/财务可行性/历史先例/估值安全/综合）。
SOTP分部估值。公司有 PE 业务和 PS 业务时，拆开各自估值再加总。防止用错了锚。
范式切换市场换了一种方式给公司标价——PE 15x 的化工股变成 PS 8x 的新材料股。这是最大的涨幅来源。

三、总控台

总控台/dashboard
系统的指挥中心。分为三大区域：

❶ 调度控制区：调度器开关（启动/暂停自动轮询）、下次轮询倒计时、A 股市场状态、产业链引擎控制。

❷ 实时进度流：SSE 推送，展示当前正在估值推演的标的一步步走到哪了。

❸ 审阅面板：对跑完的报告做「通过/有条件通过/驳回」裁决——通过则创建追踪令，进入持续跟踪。

📌 怎么用：确保调度器在运转→有新标的时点击代码跳转报告→读完回来在审阅面板裁决。

四、身外化身

身外化身/avatar
AI 对话研报工具。输入股票代码或名称 + 问题，系统运行七步分析流程输出一份手写级投资研判。适合：快速探查不在追踪列表中的新标的、对已有报告做补充分析。
📌 跑完需要几分钟，不是秒回。分析过程中可以看到每一步的进度。

五、追踪令

追踪令详情/tracking
估值报告审阅通过后生成的持续跟踪档案。首页的「跟踪令」面板是概要视图，这里是完整详情。

5.1 论点支柱 (Pillars)

当初为什么买这只票——拆成 3-5 条可验证的支柱，每条有验证日期。

状态怎么办
pending 还没到验证时间继续持有
on_track 趋势向好持有，可加仓
at_risk 危险信号减仓，密切关注
broken 论点破灭清仓

5.2 催化剂日历

未来影响股价的关键事件时点——业绩预告、政策发布、产品认证、客户导入。每个催化剂标注了利好(bull)和利空(bear)两种兑现结果。

5.3 价格日志

每个交易日的收盘价、PE、市值、涨跌幅自动记录。一眼看到趋势变化。

5.4 A 股专检

质押率、限售解禁、两融余额、内幕交易减持——自动按频率检查，有问题标红。

5.5 退出条件

每只标的预设退出规则——触发就卖，不犹豫。
