# 环境配置规范

> 适用于：估值重构引擎 V8 + Coze 万业谱预研管线

---

## 一、配置加载优先级

系统通过 `env_config.py` 统一管理所有密钥和配置，加载优先级：

```
os.environ  >  .env 文件  >  valuation_app/config.json
```

环境变量优先级最高，适合容器化部署；`.env` 适合本地开发；`config.json` 作为兜底。

---

## 二、必需密钥（5 项）

### 2.1 `.env` 文件

位置：`估值重构引擎_V5/.env`

```bash
# 估值重构引擎 V5 — 环境变量
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
COZE_SAT_TOKEN=sat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
INVESTODAY_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TUSHARE_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
VOLC_AGENT_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 2.2 密钥说明

| 变量名 | 用途 | 获取方式 | 消费模块 |
|--------|------|---------|---------|
| `DEEPSEEK_API_KEY` | DeepSeek LLM API 调用 | [platform.deepseek.com](https://platform.deepseek.com) → API Keys | 所有 Agent、Coze 工作流、产业链分析 |
| `COZE_SAT_TOKEN` | Coze 云数据库读写 | Coze 开放平台 → 个人设置 → SAT Token | 万业谱写入、天机卷标记 |
| `INVESTODAY_API_KEY` | investoday-api 金融数据 | investoday 数据平台 | Agent-1 数据锻造（40+ 端点） |
| `TUSHARE_TOKEN` | Tushare Pro 金融数据 | [tushare.pro](https://tushare.pro) → 用户中心 → 接口 Token | Agent-1 补充数据、代码校验、股价窗口 |
| `VOLC_AGENT_KEY` | 火山引擎 Agent API | 火山引擎控制台 → 豆包 Agent | 产业链联网搜索、个股投资地图 |

### 2.3 `.env.example` 模板

```bash
# 估值重构引擎 V5 — 环境变量模板
# cp .env.example .env 并填入密钥

DEEPSEEK_API_KEY=sk-your-key
COZE_SAT_TOKEN=sat-your-token
INVESTODAY_API_KEY=your-key
VOLC_AGENT_KEY=your-key
TUSHARE_TOKEN=your-tushare-token
```

### 3.2 配置字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `deepseek_api_key` | string | `""` | DeepSeek API Key（fallback，优先用 `.env`） |
| `coze_sat_token` | string | — | Coze SAT Token |
| `investoday_api_key` | string | — | investoday API Key |
| `default_output_dir` | string | `"./reports"` | 估值报告输出目录 |
| `coze_workspace_id` | string | — | Coze 工作空间 ID |
| `polling_interval_sec` | int | 3600 | 调度器轮询间隔（秒） |
| `agent0_database_id` | string | — | 万业谱（Agent-0 语料库）Coze DB ID |
| `output_database_id` | string | — | 估值输出 Coze DB ID |
| `detail_database_id` | string | — | 估值明细 Coze DB ID |
| `server_host` | string | `"0.0.0.0"` | FastAPI 服务器绑定地址 |
| `server_port` | int | 8080 | FastAPI 服务器端口 |
| `tianji_poll_interval_sec` | int | 1800 | 天机卷轮询间隔（秒） |
| `scheduler_enabled` | bool | true | 启用调度器自动轮询 |
| `wangqi_enabled` | bool | false | 启用望气台 |
| `tushare_token` | string | — | Tushare Token |
| `volc_agent_key` | string | — | 火山引擎 Agent Key |

### 3.3 Coze 数据库 ID 映射

| 数据库 | ID | 用途 |
|--------|----|------|

| 万业谱 | `7639784337973477386` | Agent-0 预研语料存储（5 维分析+交叉验证） |
| 估值输出 | `7640094415800860724` | 估值报告主表 |
| 估值明细 | `7644911309938589711` | 估值报告明细表 |

### 3.4 硬编码密钥位置（Coze 工作流节点）

以下文件在 Coze Code 节点中硬编码了密钥（非从 `.env` 读取），部署时需替换：

| 文件 | 硬编码密钥 |
|------|-----------|
| `src/coze_workflow/n3_field_probes.py` | `DEEPSEEK_KEY`, `BOCHA_KEY` |
| `src/coze_workflow/n9_writer.py` | `COZE_TOKEN`, `DB_WANYEPU`, `DB_TIANJI` |

> **警告**：这些密钥在 Coze Code 节点中以明文形式运行，Coze 平台的 Code 节点环境变量机制不同于本地开发。如需重构，建议将这些节点迁移到本地 Pipeline 并统一使用 `env_config.py`。

## 四、API 端点映射配置

### 4.1 `config/endpoint_mapping.yaml`

位置：`估值重构引擎_V5/config/endpoint_mapping.yaml`

该文件定义了 investoday-api 的完整端点映射（389 行），按 6 层组织：

```
第 1 层：公司基本面快照（P0 优先级）
  ├── stock-quote/realtime          实时行情
  ├── stock/finance/valuation      估值指标+行业/历史排名
  ├── stock/income-statements-ttm  利润表 TTM
  ├── stock/balance-sheets-ttm     资产负债表 TTM
  ├── stock/cash-flows-ttm         现金流量表 TTM
  ├── stock/dupont-analysis        杜邦分析
  ├── stock/industries             申万行业分类
  ├── stock/score                  个股综合得分
  ├── stock/operating-reviews      经营评述（管理层讨论）
  ├── stock/fin-der-inds           财务衍生指标
  └── stock/finance/profit-ability 盈利能力指标+历史排名

第 2 层：行业与可比公司（P1）
  ├── industry-quote/realtime       行业实时行情
  ├── industry/forecasts            行业增长预测
  └── stock/fin-ind-sw-rnk-q       行业内财务排名

第 3 层：事件数据（P0）
  ├── stock/major-contracts         重大合同
  ├── stock/arbitration-cases       诉讼仲裁
  ├── stock/violation-penalties     违规处罚
  ├── report/research               研究报告
  └── stock/consultations           互动问答

第 4 层：市场状态（P1）
  ├── stock-quote/capital-flow      资金流向
  ├── economic/gover-bond-yield     国债收益率
  ├── economic/money-supplies       货币供应量
  └── economic/social-financing-sto 社融

第 5 层：催化路径（P2）
  ├── stock/report-schema           财报披露日程
  └── stock/forecast-ratings        分析师一致预期

第 6 层：产业链利润流（P0）
  ├── chain/industry-info           产业链行业分类
  ├── chain/pro-relation            产品上下游关系
  └── chain/pro-ind-maps            产品行业映射
```

详细端点参数、返回字段定义见 `config/endpoint_mapping.yaml` 原文。
