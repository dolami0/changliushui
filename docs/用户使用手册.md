# 长流水 — 用户使用手册

> 以炒股捕获十倍股为宗旨的赛博仙门。本手册介绍系统结构、各板块功能，以及如何利用本平台开展 A 股投研工作。

---

## 一、系统概览

长流水是一个自动化 A 股估值重构系统，核心理念是**用事件驱动的方式发现市场定价错误**。它不是荐股工具，而是一个帮你做"第二层思维"的工作台——当市场在为事件 A 定价时，系统帮你判断事件是否已被充分计价、当前估值锚是否合理、以及预期差有多大。

### 技术架构（用户视角）

```
事件输入 (天机峰/Coze) → 自动管线处理 (4-Agent) → 估值报告输出 → 追踪令持续监控
                              ↓
                         仪表盘 (实时监控)
```

系统将各个工作模块比作修仙宗门中的十大机构，各司其职：

## 三、各板块详细说明

### 3.1 宗门（首页）

**访问路径**：`/`

首页展示宗门十大机构及其运转状态。按职能分为三组：

**天机峰四司**（情报采集与分析）：
- 天眼司 — 事件瀑布流与响应分级
- 望气台 — 产业链利润流分析
- 寻龙殿 — 涨停板龙头股狙击（未完工）
- 妙音阁 — 用户问询触发研发工作流

**核心估值与追踪**：
- 估值殿 — 4-Agent 估值重构管线
- 追踪司 — 追踪令系统

**指挥与交互**：
- 总控台 — 中枢调度与审阅
- 身外化身 — AI 对话交互
- 藏经阁 — 知识库
- 炼器房 — 系统参数管理

每个机构卡片显示状态指示灯（绿=运转中 / 蓝=监控中 / 橙=推演中 / 灰=待命中/静置中）、机构代号和当前任务。点击卡片进入详情页可阅读完整的业务流程说明。

**投研用途**：快速了解各机构运转状态，确认系统全链路健康。绿色指示灯越多，系统越活跃。

### 3.2 仪表盘（总控台）★ 核心

**访问路径**：`/dashboard`

这是整个系统的指挥中心，包含以下功能模块：

#### a) 调度器控制
- **状态显示**：调度器运行/停止状态、上次/下次轮询时间
- **倒计时**：距离下次自动轮询的实时倒计时（像素字体显示）
- **手动触发**：点击「手动触发」按钮立即启动一轮估值管线处理
- **启停控制**：可暂停/恢复自动轮询

#### b) 管线进度监控
- **活跃任务面板**：显示正在处理的股票，按阶段展示（预路由 → 数据炼器 → 路由判决 → 推演裁决 → 报告输出）
- **阶段可视化**：每个阶段用圆点表示状态（灰=等待 / 绿=完成 / 红=报错）
- **展开详情**：点击活跃任务可展开查看当前进度详情
- **历史任务记录**：已完成任务的列表，含完成时间、模型选择、收益率预估

#### c) 报告审阅
- **手动审阅**：触发对所有已完成报告的批量质量审查
- **审阅结果**：评级分布（A/B/C/D）、各层平均分、系统性高频问题标记
- **审阅记录浏览**：可查看历史审阅文件列表和内容

#### d) 产业链调度（望气）
- 独立的产业链分析调度器，与主估值管线并行运行
- 状态监控和手动触发

**投研工作流**：
1. 每天早上开盘前，检查仪表盘确认调度器正常运行
2. 如有新事件触发，观察管线处理进度
3. 处理完成后，点击「手动审阅」查看本轮报告质量评级
4. 优先阅读评级为 A/B 的报告，C/D 级别需谨慎对待

---

### 3.3 天机峰（情报站）★ 核心

**访问路径**：`/tianjifeng`

天机峰是情报采集与分析的中心，包含四个子模块（Tab 切换）：

#### a) 天眼 — 事件瀑布流
- 实时展示从 Coze Agent0 数据库拉取的所有 A 股事件
- 每条事件标注**响应等级**（L0-L5），颜色越鲜艳越值得关注：
  - **L5 道变**（紫色）：范式级事件，行业底层逻辑变化
  - **L4 天兆**（橙色）：重大催化，估值锚可能切换
  - **L3 雷动**（黄橙色）：重要事件，需评估计价程度
  - **L2 风起**（青色）：普通事件，常规跟踪
  - **L1 微澜**（灰色）：低影响事件
  - **L0 尘外**：噪音，可忽略
- 每条事件包含：股票代码、事件摘要、投资主题、传导链推演、反方观点
- 支持分页浏览（每页 50 条）

#### b) 望气 — 产业链利润流
- 展示产业链上下游利润分配 Sankey 图
- 分析利润在产业链各环节的流向和分配比例
- 帮助判断公司在产业链中的议价地位

#### c) 寻龙 — 产业定位分析
- 公司在产业链中的卡位评估
- TAM 估算、渗透率分析、竞争格局

#### d) 妙音 — 事件解读
- 对特定事件的深度文本解读
- LLM 生成的多维度分析

**投研工作流**：
1. 每天浏览「天眼」中的 L3+ 事件，特别关注 L4/L5
2. 阅读事件的「投资主题」和「事件推演传导链」，形成初步判断
3. 用「望气」查看相关产业链的利润流向，验证公司在产业链中的位置
4. L4/L5 事件会自动触发估值重构管线，等待仪表盘处理完成即可查看报告

### 3.4 估值报告 ★ 核心产出

**访问路径**：`/report/:stock_code` 或 `/report/v4/:stock_code`

这是管线最终的知识产出，一份完整的估值重构报告包含以下章节：

| 章节 | 内容 |
|------|------|
| 1. 报告摘要 | 加权涨幅、不对称比、质量评级、交易标注 |
| 2. 投资命题 | 事件驱动的「如果-那么」命题 |
| 3. 路由决策 | 选择的估值模型及理由 |
| 4. 三情景估值 | 悲观/基准/乐观三种情景的数字推演 |
| 5. 市场清醒度检测 | BS 检测器、隐含增长率反解 |
| 6. 案例参照 | V3 案例库中最相似的十倍股历史案例 |
| 7. 反向 DCF | 将当前市值反解为隐含增长率，与叙事对比 |
| 8. 非对称评分 | 涨跌不对称比（核心决策指标） |
| 9. 置信度评估 | 数据质量、模型适配度、叙事自洽性 |
| 10. KMI 关键监测指标 | 需要持续跟踪的证伪/证实信号 |

**关键指标解读**：

- **概率加权涨幅（Probability-Weighted Upside）**：综合考虑三情景概率后的期望收益率。>20% 值得深入，>50% 高价值
- **不对称比（Asymmetry Ratio）**：上涨空间与下跌空间的比值。>2x 意味着涨的空间是跌的 2 倍以上，是核心风控指标
- **质量评级（Quality Flag）**：HIGH_QUALITY（数据充分+逻辑自洽）> ADEQUATE（可接受）> SPECULATIVE（投机级，数据缺失或逻辑漏洞较多）

**移动端**：系统会自动检测移动设备并切换到移动端优化版（手风琴折叠布局）。

### 3.5 追踪令（持仓监控）★ 核心

**访问路径**：`/tracking`

对已生成估值报告的目标进行持续追踪：

- **投资论点档案**（Thesis Tracker）：核心命题、支柱评分卡
- **催化剂日历**：已触发/待触发催化事件时间线
- **价格追踪**：入场价、目标价、当前价、收益率曲线
- **风险监控**：关键风险的实现概率和影响评估
- **论点状态**：pending / on_track / at_risk / verified

**投研工作流**：
1. 对估值报告中 `upside > 20%` 且 `quality_flag != SPECULATIVE` 的标的，加入追踪令
2. 每周复盘一次：催化剂是否按预期兑现？论点支柱是否有裂缝？
3. 论点支柱评分下滑或关键催化剂证伪 → 触发卖出审查

### 3.6 身外化身（AI 助手）

**访问路径**：`/avatar` 或 `/avatar-cc`

交互式 AI 对话模块，可直接查询估值报告中的具体问题：

- **模块化上下文**：可选择加载报告的特定章节（估值摘要、三情景、BS 检测、路由决策、财务数据等）作为对话上下文
- **记忆中枢**：
  - **灵光**（灵感笔记）：保存投研中的零散想法和发现
  - **案例库**：浏览历史十倍股案例
  - **追踪数据**：查看追踪令中保存的结构化数据

**投研用途**：
- 读完报告后有疑问，不用翻原始数据，直接问 AI
- "这个标的的 ROIC 为什么这么低？" → AI 会基于报告内容回答
- "和上次分析的 XX 股比，哪个更值得投？" → AI 会对比两份报告
- 随手保存灵感笔记，积累个人投研知识库

## 四、典型投研工作流

### 日常工作流（每日 30 分钟）

```
09:00  打开仪表盘 → 确认调度器运行、检查昨夜处理结果
09:05  浏览天机峰「天眼」→ 筛选 L3+ 事件
09:15  对感兴趣的事件，查看投资主题和传导链
09:20  等待管线自动处理（或手动触发）
09:25  阅读生成的估值报告，重点关注：
       - 不对称比是否 > 2x
       - 三情景 bull/bear 概率分配是否合理
       - BS 检测器是否发现市场定价异常
       - 反向 DCF 隐含增长率与叙事是否匹配
09:30  对高潜力标的 → 加入追踪令，设置催化剂提醒
```

### 每周复盘（每周日 1 小时）

```
1. 打开追踪令，逐只回顾：
   - 催化剂是否按预期兑现？
   - 论点支柱评分是否有变化？
   - 是否需要调整目标价或卖出？
2. 浏览仪表盘「审阅记录」→ 关注本周所有报告的评级分布
3. 如发现评级普遍偏低或系统性标记 → 可能是数据源问题
4. 检查藏经云中的方法论是否需要更新
```

### 事件驱动工作流（突发重大事件）

```
1. 确认天机峰是否已抓取该事件（检查「天眼」最新页）
2. 如已抓取 → 等待自动处理或手动触发仪表盘
3. 重点关注：
   - 响应等级是否 ≥ L4（天兆/道变）
   - 事件是「系列延续」还是「范式转移」（后者更需要逆向思维）
   - 市场是否已经部分计价（BS 检测器结果）
4. 报告生成后 → 在身外化身的对话中深入追问
5. 决定是否建仓/加仓 → 加入追踪令
```

## 五、常见问题

**Q: 仪表盘显示"无待处理记录"？**
A: Coze Agent0 库中没有新的未处理事件。这不是 bug，说明最近没有触发管线的新事件。检查天机峰「天眼」是否有新事件入库。

**Q: 估值报告的 quality_flag 是 SPECULATIVE，还能信吗？**
A: SPECULATIVE 意味着数据缺失或逻辑存在明显漏洞。建议：①检查报告中标注的数据缺口 ②降低仓位 ③等待更多数据后再决策。不可作为重仓依据。

**Q: 不对称比 > 5x 是不是一定值得买？**
A: 不是。不对称比是期望值工具，不是圣杯。如果 bear 概率被低估，不对称比会被虚增。始终交叉验证 BS 检测器和反向 DCF 的结论。

**Q: 移动端体验不好？**
A: 估值报告页已做移动端适配（手风琴折叠布局）。其他页面建议桌面端使用以获得最佳体验。

**Q: ngrok 外网访问报告加载失败？**
A: 检查后端是否在线（`仪表盘状态`），确认 ngrok 隧道指向 8080 端口，刷新页面重试。Coze API 数据不走 ngrok 隧道（直连），ngrok 仅影响报告和追踪令的加载。

## 六、系统限制与注意事项

1. **数据时效性**：财务数据来自公开财报（季报/年报），可能滞后 1-3 个月
2. **模型假设**：所有估值模型基于假设参数，假设变动可能导致结论翻转
3. **案例库偏差**：V3 案例库来自十倍股幸存者样本，存在幸存者偏差
4. **LLM 输出不确定性**：估值报告由 LLM 生成，相同输入可能产生不同输出细节
5. **不是投资建议**：系统输出为投研辅助工具，不构成买卖建议。最终决策责任在用户
