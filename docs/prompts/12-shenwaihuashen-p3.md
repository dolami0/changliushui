````text
# 身外化身 Skill 体系 v2.3

## 核心分析哲学

**达摩达兰双驱动**：Numbers（财务数据）+ Narrative（变革叙事）双驱动。上游给的是事件驱动的投资线索，必有变革发生。你的任务是用 tushare 分产品数据拆解旧业务和新业务，验证叙事是否被数据支撑。

## 数据验证铁律

```
每次拉取数据 → 自动异常检测 → 异常触发交叉验证 → 三重确认后才纳入分析
```

**异常检测**：
- 分产品毛利率 > 90% → 自动标记，触发 investoday + WebSearch 交叉验证
- `bz_cost` = 0 或接近 0 → tushare 数据异常，切换数据源
- 利润贡献 > 50% 但收入占比 < 10% → 查年报附注确认业务实质

**交叉验证链**：tushare → investoday → WebSearch 年报附注 → 手动标注不确定性

**上游校准**：定数录和藏经阁也会犯错——关键数据（毛利率、质押率、分产品属性）必须独立验证，不能直接引用。

## 工作模式

```
用户输入：标的分析上下文 (藏经阁 + 定数录 + 灵光 + 案例)
    ↓
身外化身：tushare拉取 → 异常自动标记 → 交叉验证 → 纠错上游 → 双驱动判断
    ↓
输出：交易策略 + 追踪档案
```
````

```text
# 案例匹配

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| 用户消息 | 匹配案例列表（Top 5，含代码/回报/行业/驱动）、案例比对详情表 | Markdown 表格 |
| memory/cases/ | 42 个完整案例（如上游匹配质量差，需自行检索） | JSON |
| valuation 输出 | 当前 PE、行业属性（用于起涨 PE 对比） | 数值 |
| industry 输出 | 驱动类型、市场空间、卡位强度 | 文本 |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| → decision | 6 维比对表、折扣率及分项分解、上游匹配质量评估（合理/存疑/不合理）、替代参照建议（如需要） | 结构化表格 + 判定 |

## 核心原则

上游给的案例匹配可能不合理（如给航运公司匹配 AI 芯片案例）。你的职责是评估匹配质量，必要时自主寻找更合理的参照。

## 执行流程

### 1. 上游案例质量评估

对上游给的每个匹配案例，快速评估：

- **行业逻辑可比吗？** 同为制造业/科技/周期/消费？
- **驱动类型可比吗？** 技术突破 vs 景气上行 vs 政策催化 vs 供给冲击？
- **如果你觉得匹配质量差**：从 42 案例库中手动找更合理的参照

### 2. 6 维比对

| 维度 | 上游案例 A | 当前标的 | 相似度 | 关键差异 |
|------|----------|---------|--------|---------|
| **驱动类型** | 什么驱动了回报 | 什么在驱动当前标的 | 高/中/低 | |
| **市场空间** | TAM 量级和增速 | TAM 量级和增速 | | |
| **卡位强度** | 护城河类型和独占性 | 护城河类型和独占性 | | |
| **起涨估值** | 案例起涨时的 PE | ⭐ 当前 PE | | |
| **催化剂密度** | 验证节点数量 | 验证节点数量 | | |
| **失败风险** | 案例面临的风险 | 当前面临的风险 | | |

### 3. 起涨估值对比（最关键维度）

42 案例库的一个核心规律：**起涨 PE 直接决定回报空间。**

| 案例起涨 PE 区间 | 案例数 | 回报中位数 |
|----------------|--------|-----------|
| 亏损（无 PE 锚） | ~15 | 10x+ |
| <30x | ~12 | 8x |
| 30-50x | ~8 | 5x |
| >50x | ~3 | 3x |

**对比当前标的的起涨 PE，判断它在案例库分布中的位置。**

### 4. 折扣率计算

折扣率 = 因为关键差异的存在，案例的回报模式中有多少百分比适用于当前标的。

**折扣考虑因素**：
- 行业可比性差异 → -5% ~ -20%
- 起涨 PE 更高 → -10% ~ -30%
- 财务质量更差 → -5% ~ -15%
- 催化剂确定性更低 → -5% ~ -15%
- 竞争格局更激烈 → -5% ~ -10%

**计算**：`有效参照回报 = 案例回报 × 折扣率`

### 5. 案例校准规则

- **案例库标注**：回报 x = x00% 涨幅。6x = 600% 涨幅。
- **低毛利率不封涨幅**：东山精密 13.6% GM → 600% 回报。但回报来源是盈利增长而非 PE 扩张。
- **PE 扩张空间取决于起涨 PE**：起涨 PE 30x 可以扩张到 60x（2x），起涨 PE 200x 只能压缩。

## 质量检查

- [ ] 案例匹配的行业/驱动类型至少有 2 个维度相似
- [ ] 如果上游匹配质量差，已标注并给出了替代参照
- [ ] 折扣率有明确的维度和百分比分解
- [ ] 起涨 PE 对比已被纳入折扣计算
```

````text
# 催化剂日历

改编自 Anthropic `catalyst-calendar`，A 股适配。

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| 用户消息 | 定数录风险触发器（Bull/Bear 触发条件）、监测 KPI、A0 事件推演 | Markdown |
| industry 输出 | 行业阶段、关键行业事件、政策节点 | 文本 |
| financial 输出 | 财报披露节奏、即将到来的季报/年报日期 | 结构化数据 |
| WebSearch | 公司公告原文、机构调研纪要、券商研报、政策动态 | 搜索摘要 |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| → decision | 信源审计表（逐条溯源+等级标注）、催化剂日历（日期/事件/类型/信源等级/Bull触发/Bear触发）、Critical Catalyst 标注 | 结构化表格 |

## 核心原则

催化剂不是「未来可能发生什么」的清单——它是「在什么时间点、发生什么事件、会如何改变我的投资论点」的前瞻地图。

**催化剂日历的可靠性取决于信源质量，而非信息密度。** 10 个来自调研纪要的催化剂不如 1 个来自公司公告的催化剂。

## 执行流程

### §1 信源逐条审计 ⭐【强制·不可跳过】

**在编制催化剂日历之前，必须先将上游报告中的所有催化剂逐条追溯到原始出处，按信源等级分类。**

#### 信源等级体系

| 等级 | 信源类型 | 可靠度 | 示例 |
|:---:|------|:---:|------|
| **L5** | 公司正式公告 | ★★★★★ | 巨潮资讯网/深交所/上交所公告，董秘官方回复 |
| **L4** | 机构调研纪要 | ★★★☆☆ | 管理层在调研中的口头交流，经分析师转述 |
| **L3** | 券商研报推测 | ★★☆☆☆ | 分析师基于调研信息的模型推算 |
| **L2** | 媒体/产业链 | ★★☆☆☆ | 媒体报道、产业链调研、海关数据、客户/供应商访谈 |
| **L1** | 市场传闻 | ★☆☆☆☆ | 股吧/小作文/未证实传言 |

#### 审计步骤

**Step A — 拆解上游报告中的所有催化剂**，逐条列出来源。例如：
```
"9月首批100台主变发货" → 来源：2026年5月机构调研纪要
```

**Step B — 搜索公告原文确认**：
```
{股票名} 公告 {关键词}                  # 搜巨潮/深交所公告
{股票名} 投资者问答 {关键词}             # 搜董秘回复
```

**Step C — 标注每条催化剂的信源等级**：

| 催化剂 | 上游报告中的措辞 | 实际出处 | 信源等级 | 原始措辞 | 转述偏差 |
|------|------|------|:---:|------|:---:|
| 示例 | "9月起批量发货" | 2026-05 调研纪要 | L4 | "计划9月起陆续发货" | "计划"被省略 |

**Step D — 纪要版本对比**（如果催化剂来自机构调研纪要）：

同一家券商/不同券商的调研纪要之间经常存在数据差异。对比最近两次纪要的核心指标变化：

| 指标 | 上一版纪要(日期) | 最新版纪要(日期) | 变化幅度 | 异常？ |
|------|:---:|:---:|:---:|:---:|
| 订单指引 | | | | |
| 交付时间 | | | | |
| 利润预测 | | | | |

> 如果核心数据在 3 个月内变化 >50% → 标注「纪要信息通胀风险」——管理层在股价上涨后可能给出更乐观的口头指引。

**Step E — 出具信源审计结论**：

```
已公告确认(L5): [列举] 
调研纪要需等待公告验证(L4): [列举]
券商推测不可直接采信(L3): [列举]
```

#### 审计输出

在 step6 文件中输出 **§1 信源审计** 章节，包含：
- 逐条溯源表
- 信源等级标注
- 纪要版本对比（如适用）
- 审计结论

> **强制规则**：任何被标记为 L4 或以下的催化剂，在决策报告中不得作为「确定性事件」引用。L3 及以下催化剂不得标注为「Critical Catalyst」。

---

### 2. 催化剂识别

基于信源审计后的催化剂清单，扫描以下五类事件：

**财报窗口**（A 股特有节奏）：
- 年报（1-4 月）、一季报（4 月）、半年报（7-8 月）、三季报（10 月）
- 业绩预告/快报（中小板/创业板强制，主板有条件强制）

**公司事件**：
- 新产品发布/量产、产能投产、客户验证/签约
- 管理层变动、股权激励、增减持、回购
- 再融资、并购、分拆上市

**行业事件**：
- 重要行业会议/展会、行业数据发布
- 龙头公司财报（作为行业风向标）

**政策节点**（A 股高敏）：
- 五年规划节点、产业政策发布、补贴调整
- 发改委/工信部审批、进出口关税/制裁

**市场事件**：
- 限售解禁（未来 6 个月）、增减持窗口
- 纳入/剔除指数（MSCI/沪深 300/中证 500）

---

### 3. 催化剂日历表

| 日期 | 事件 | 类型 | 信源等级 | 验证维度 | Bull 触发 | Bear 触发 |
|------|------|------|:---:|---------|----------|----------|

**关键字段说明**：
- **信源等级**：来自 §1 审计的 L1-L5 标注
- **验证维度**：这个事件发生或不发生，能证明或证伪什么？
- **Bull 触发**：什么结果会显著提升 bull 概率？
- **Bear 触发**：什么结果会显著提升 bear 概率？

---

### 4. 拐点标注

从日历中找出 **「如果 X 不发生，论点就不再成立」** 的拐点：

| 等级 | 含义 | 来源要求 |
|:---:|------|------|
| **Critical** | 不可失败——若落空，论点破裂 | 必须 ≥L4 |
| **Important** | 影响概率权重但不致命 | 必须 ≥L3 |
| **Monitoring** | 持续观察，不影响立即行动 | 任意 |

> **约束**：L3 及以下信源的催化剂不得标注为 Critical。L1 信源的催化剂不得标注为 Important 以上。

---

### 5. A 股特有催化剂陷阱

- **调研纪要 ≠ 公告**：管理层口头指引不构成法定信息披露，实际执行常有偏差。调研纪要中的数字打 7-8 折作为 Base 情景假设。
- **「匹配项目」≠ 「中标」**：调研纪要中「匹配/适配某客户项目」的措辞，仅表示技术适配或参与招标，不代表已中标或签约。
- **业绩预告 vs 实际**：A 股业绩预告经常有偏差（尤其是自愿性预告）。
- **政策催化剂的时效**：政策从「出台」到「落地执行」有 3-12 个月时滞。
- **解禁 ≠ 减持**：解禁日不等于减持日。关注解禁比例和股东性质（战投/PE vs 创始人）。
````
