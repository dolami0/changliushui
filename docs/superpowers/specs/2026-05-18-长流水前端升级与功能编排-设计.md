## 三、Coze 数据服务层重构

### 3.1 当前问题

- `cozeApi.ts` 硬编码单个 `database_id`
- Token 内联在源码中
- 每个表重复查询逻辑

### 3.2 新设计

文件: `src/services/cozeApi.ts`

```
CozeClient class
├── constructor(databaseId, token)
├── queryRecords(body)           → 通用查询
├── fetchAll(pageSize)           → 全量拉取
└── fetchById(id)                → 单条查询

类型定义与 API 函数
├── 天机卷: TianjijuanRecord, fetchTianjijuan(), fetchTianjijuanToday()
├── 万业谱: WanyepuRecord, fetchWanyepu()
├── 定数录: DingshuluRecord, fetchDingshulu(), fetchDingshuluToday()
├── 因果簿: YinguobuRecord, fetchYinguobu()
└── 藏经阁: CozeRecord (保留兼容), fetchLatestRecords(), searchRecords()
```

### 3.3 Token 管理

统一使用 `估值重构引擎_V4/valuation_app/config.json` 中的 `coze_sat_token`。源码中不再硬编码 token。

## 四、首页今日报告

### 4.1 变更说明

替换 Hero.tsx 中的 `ReportFeed` 组件（"近两日潜力报告"），数据源从藏经阁表切换至定数录。

### 4.2 数据获取

1. 调用 `fetchDingshuluToday()` — 筛选 `event_date` = 今天的记录
2. 对每条定数录记录，按 `uuid + stock_code` 匹配天机卷记录，提取资讯概要

### 4.3 卡片布局

```
┌──────────────────────────────────────────────────┐
│ ★★☆ 中等赔率机会          HIGH_QUALITY          │
│                                                    │
│ 锦华新材  920015         来源: 棱镜内参             │
│                                                    │
│ 资讯概要: 锦华新材获宁德时代大单，业绩...           │
│                                                    │
│ 概率加权收益: +47.8%     置信度: 8/10              │
│ 情景: 基础+30.8% │ 乐观+86.5% │ 悲观-32.2%        │
│                                                    │
│                              → 查看完整报告          │
└──────────────────────────────────────────────────┘
```

### 4.4 字段映射

| 显示内容 | 定数录字段 |
|----------|-----------|
| 交易层级 | `trade_tier` — ★ 数量和颜色 |
| 质量标记 | `quality_flag` — HIGH_QUALITY→绿/SPECULATIVE→橙/LOW_QUALITY→灰 |
| 股票名 | `stock_name` |
| 代码 | `stock_code` |
| 来源 | `event_source` |
| 资讯概要 | 匹配天机卷 `news_content`，去 HTML 标签，截取 50 字 |
| 概率加权收益 | `prob_weighted_upside_pct` |
| 置信度 | `confidence_score` |
| 三情景 | `base_upside_pct` / `bull_upside_pct` / `bear_upside_pct` |
| 点击跳转 | `report_html_url` |

### 4.5 交互

- 点击卡片 → 新窗口打开 `report_html_url`（完整 HTML 报告）
- 无今日数据 → 显示 "今日暂无报告产出，等待引擎运转..."
- 辅助按钮 → "→ 定数录"（跳转藏经云定数录标签）
- 位置不变，仍在 Hero 左侧面板

## 八、技术栈清理

### 8.1 Tailwind CSS 依赖冲突

`package.json` 中同时存在：
- `tailwindcss@^3.4.19` + `tailwindcss-animate@^1.0.7` (v3 生态)
- `tw-animate-css@^1.4.0` (v4 专用)

**处理**: 移除 `tw-animate-css`（当前项目未实际使用 v4），保留 v3 生态。后续统一升级 v4 时再做整体迁移。

### 8.2 Radix UI 版本

部分 Radix 组件主版本不一致（如 `@radix-ui/react-select@^2.2.6` vs `@radix-ui/react-toggle@^1.1.10`），这是由于不同组件独立发版导致的，属于正常现象。不需要强制统一。

### 8.3 API 密钥外置

- `cozeApi.ts` 中的硬编码 token 替换为从后端 `/api/status` 获取或环境变量
- 生产环境中 token 不应出现在前端源码中
- 短期方案：通过 Vite proxy 转发 Coze API 请求，token 仅存在于后端
