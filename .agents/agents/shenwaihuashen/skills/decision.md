# 综合决策

决策流程的最后一步——将所有分析线索编织成完整的判断和可执行的交易策略。

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| data-verify 输出 | 验证后的关键数据、数据矛盾清单、异常标记 | 结构化数据 |
| industry 输出 | 一句话产业逻辑、卡位评级、竞争矩阵 | 文本 + 表格 |
| financial 输出 | 新旧业务拆解表、Numbers验证Narrative判定、财务健康评级、质押确认 | 表格 + 判定 |
| valuation 输出 | 起涨估值检查、BS检测结果、可比公司表、修正三情景、不对称比、预期差 | 数值 + 表格 |
| case-match 输出 | 6维比对、折扣率、匹配质量评估 | 表格 |
| catalyst 输出 | 催化剂日历、Critical Catalyst | 表格 |
| memory/lingguang/ | 4 条灵光原文（核心哲学/风控铁律/起涨估值/毛利率天花板） | JSON |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| 用户 | 标准化投资决策报告 | Markdown → `D:\长流水\output\{ticker}_{date}\decision-{YYYYMMDD}-{ticker}.md` |
| → thesis (如通过) | 论点基础数据（pillars/risks/exit conditions/catalyst calendar） | 内存传递 |

## 执行流程

### 1. 风险扫描

从所有前置 Skill 的输出中提取风险，按四类整理：

**致命风险**（触发即否决）：
- 大股东质押率 > 50%
- 业绩连续两季下滑
- 财务造假迹象
- 核心专利/牌照面临挑战
- 退市风险

**经营风险**：客户/供应商集中度、技术替代、产能爬坡、管理层
**市场风险**：解禁压力、两融异常、行业政策、汇率/地缘
**估值风险**：PE 压缩、业绩不达预期导致戴维斯双杀

| 风险 | 类型 | 概率 | 影响 | 应对策略 |
|------|------|------|------|---------|

### 2. 灵光校准

将前置分析的结果与 4 条灵光逐一对照：

| 灵光 | 匹配 | 判决 | 依据 |
|------|------|------|------|
| **核心投资哲学** | 绿/黄/红 | 是否满足小市值+大产业+强卡位？ | 引用 industry 和 data-verify 中的具体数据 |
| **风控铁律** | 绿/红 | 质押率/业绩趋势/仓位约束 | 引用 financial 中的质押和业绩数据 |
| **起涨估值定律** | 绿/红 | PE 是否 < 50x？如超过，缓解因素？ | 引用 valuation 中的 PE 数据 |
| **毛利率天花板定律** | 绿/黄/红 | GM 是否支撑预期回报类型？ | 引用 financial segment 和案例对照 |

**冲突处理规则**：
- 4 条一致绿灯 → Conviction +20
- 风控铁律红灯 → **自动否决**（不可妥协）
- 起涨估值定律红灯 → 最低「有条件通过」，不得「通过」
- 毛利率定律黄灯 → 下调 bull 情景的 PE 扩张幅度
- 核心投资哲学不满足 → Conviction -30

### 2.5 三道防线（灵光校准后强制执行）

灵光校准完成后，执行以下三项独立检查。每一项都可能产生额外的 Conviction 折扣：

**防线 ① — 竞对扫描**

WebSearch `{竞对名} {赛道} 最新进展 2026`，回答：竞争对手最近有没有新突破？

| 竞对进展 | 折扣 |
|------|:---:|
| 竞对已在同一赛道出货/获客 | -3 到 -5 |
| 竞对刚发布类似产品但尚未量产 | -1 到 -2 |
| 竞对无可见进展 | 0 |

**防线 ② — 管理层行为**

检查：实控人/董事近 3 个月内有无减持公告？减持计划是否在执行中？有无增持？

| 管理层行为 | 折扣 |
|------|:---:|
| 实控人大额减持中(>1%总股本) | -5 到 -10 |
| 多名高管同步减持 | -5 |
| 无减持，或有增持 | 0 / +5 |

**防线 ③ — 组合集中度**

统计 `memory/tracking/` 中已有标的，与新标的行业重叠度：

| 重叠情况 | 折扣 |
|------|:---:|
| 同赛道已有 ≥3 个标的 | -8 |
| 同赛道已有 2 个标的 | -5 |
| 同赛道 0-1 个标的 | 0 |

**这三道防线的检查结果写入决策报告的灵光校准表格下方，作为额外行。**

### 3. 综合判断

| 结论 | 条件 | Conviction 要求 |
|------|------|----------------|
| **通过** | 灵光全绿 + 不对称比 > 2.0 + 无致命风险 | ≥ 70 |
| **有条件通过** | 产业成立但估值/时机不对 | 40-69 |
| **否决** | 致命风险触发 / 灵光多红灯 / 不对称比 < 1.0 | < 40 |

### 4. 交易策略（必须包含）

| 要素 | 内容 |
|------|------|
| **建议仓位** | X%（不超过 20%） |
| **建仓方式** | 一次性 / 分批 / 回调买入（给出具体价格区间） |
| **止损位** | 什么价格/条件触发清仓 |
| **目标价** | Base 情景目标价和时间框架 |
| **加仓条件** | 什么信号出现可以加仓 |
| **减仓条件** | 什么信号出现应该减仓 |
| **重新评估条件** | 如为「否决」或「有条件通过」，什么变化后需要重新推演？ |

### 5. 输出决策报告

标准化 Markdown 报告，写入 `output/decisions/decision-{YYYYMMDD}-{ticker}.md`。

报告结构见 AGENT.md「输出规范」章节。
