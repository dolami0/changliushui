# 财务诊断

改编自 Anthropic `earnings-analysis` + 达摩达兰双驱动，A 股适配。

## ⚠️ 方法适用性检查

| 方法 | 前置条件 | 不满足时 |
|------|---------|---------|
| **ROIC vs WACC 比较** | ROIC 有意义（非金融/非初创） | ⚠️ 标注行业特殊性 |
| **OCF/NI 质量检查** | NI > 0 | ⚠️ 分母为负时跳过比值，改看 OCF 绝对值趋势 |
| **分产品拆解** | tushare `fina_mainbz` 返回有效数据 | ⛔ bz_cost=0 或 GM>90% 触发异常检测 |
| **季度趋势分析** | >4 季度数据可用 | ⚠️ 标注「数据窗口短，置信度有限」 |

### 标记说明

**【必填】** 标记的条目不可跳过。若 tushare 无法覆盖（如应收/存货/商誉/扣非等资产负债表数据），必须走 WebSearch 兜底：

```
{股票名} {年份}年报 资产负债表 应收账款 存货
{股票名} {年份}年报 扣非净利润 归母净利润
```

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| 用户消息 | 定数录公司基座（ROIC/毛利率/营收TTM/净利TTM/净资产/WACC）、经营现金流、现金/有息负债 | Markdown |
| data-verify 输出 | 验证后的 PE/市值、tushare 拉取的 segment/fina/income 数据 | 结构化数据 |
| industry 输出 | 行业阶段、新业务 Narrative（如「CIPB 驱动转型」） | 文本 |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| → valuation/decision | 新旧业务拆解表（收入/毛利/增速）、四维诊断结论、Numbers验证Narrative的四种结果判定、财务健康评级、质押率确认 | 结构化表格 + 判定 |

## 核心原则

**Numbers 要独立验证 Narrative**：不因为 Narrative 说「新业务高毛利」就假设 Numbers 支持它——去 tushare 拉分产品数据，逐项对照。

## 执行流程

### 1. 数据拉取（自动异常检测）

```bash
python data_helper.py segment <code>     # 分产品拆解 + 异常标记
python data_helper.py fina <code> 8      # ROE/毛利率/净利率/负债率 8 季度趋势
python data_helper.py income <code> 8    # 利润表 8 季度
python data_helper.py pledge <code>      # 质押
```

**看到 `ANOMALY` 标记 → 立即触发 cross-verify**（investoday + WebSearch 年报附注）

### 2. 分产品拆解 — Numbers 验证 Narrative 的核心

从 `segment` 输出中提取：

| | 传统业务 | 新业务/Narrative驱动产品 | 其他 |
|---|---------|------------------------|------|
| 产品名称 | | | |
| 收入 | XX 亿 (XX%) | XX 亿 (XX%) | |
| 毛利率 | XX% | **XX%（如有 ANOMALY 标记则交叉验证）** | |
| 毛利润贡献 | XX% | XX% | |
| 同比增速 | | | |

**关键判断**：
- 新业务毛利率是否显著高于传统业务？→ 如果是，Narrative 被 Numbers 支撑。如果不是，Narrative 存疑。
- 新业务利润贡献占比是否 > 收入占比？→ 如果是，变革正在加速。
- 如果毛利率 >90% 或 <0% → **ANOMALY**。制造业「其他业务」GM>90% 几乎必定是废料/贸易收入，非主营业务。

**A 股陷阱清单**：
- 「其他业务(补充)」在制造业中 = 废品废料收入（GM 天然 90%+）
- tushare `fina_mainbz` 部分公司 `bz_cost` = 0 或极低，导致算出的毛利率虚高
- 新业务如果未单独列示 → 收入还不够显著，Narrative 超前于 Numbers

### 3. 成长性诊断

**营收增速趋势**（近 8 季度，画方向不画点）：
- 加速 / 稳定 / 减速？
- 新业务 vs 传统业务的增速差距
- 如果减速：是基数效应还是需求疲软？

**利润增速 vs 营收增速**：
- 利润增速 > 营收增速 → 经营杠杆在释放（好）
- 利润增速 < 营收增速 → 费用侵蚀/竞争加剧（警惕）

**扣非 vs 归母**：非经常性损益占比是否 >30%？ **【必填】**

**合同负债/预收款**（如有季度数据）：未来收入的领先指标

### 4. 盈利性诊断

**毛利率趋势**（近 8 季度）：方向比绝对值重要。上升/稳定/下降？

**拆解毛利率变动**：
- 如果是新业务占比提升驱动 → 结构性改善（可持续）
- 如果是原材料降价/一次性因素 → 周期性（不可持续）

**ROIC vs WACC**：是否跨越价值创造门槛？
- ROIC > WACC 且差距在扩大 → 好
- ROIC < WACC 但趋势在改善 → 关注（可能是暂时的）
- ROIC < WACC 且差距在扩大 → 预警

**ROE 杜邦拆解**：净利率 × 周转率 × 杠杆。改善或恶化来自哪个因子？ **【必填】**

### 5. 现金流质量诊断

**经营现金流/净利润（OCF/NI）**：
- > 1.0 → 好，利润是现金
- 0.5-1.0 → 关注
- < 0.5 → 预警，利润质量差
- < 0 → 红色警报。但需要判断：是因为新业务 CAPEX 投入期（可接受），还是传统业务也在烧钱（不可接受）？

**CAPEX / 折旧**：>>1 = 在投入，<1 = 在吃老本

**应收账款/营收**趋势：上升 = 渠道压货或回款恶化 **【必填】**
**存货/营收**趋势：上升 = 滞销或囤货 **【必填】**

### 6. 资产负债健康度

| 指标 | 安全 | 关注 | 危险 |
|------|------|------|------|
| 资产负债率 | <40% | 40-60% | >60% |
| 现金/有息负债 | >1.0 | 0.5-1.0 | <0.5 |
| 商誉/净资产 | <10% | 10-30% | >30% |

### 7. 综合判断

**Numbers 验证 Narrative 的四种结果**：

| Numbers vs Narrative | 含义 | 行动 |
|---------------------|------|------|
| Numbers 支撑 Narrative | 故事有数据支持 | 继续推演 |
| Numbers 部分支撑 | 方向对但进度慢 | 下调概率权重 |
| Numbers 不支持 | 故事超前于现实 | ⚠️ 标注 speculative |
| Numbers 证伪 Narrative | 数据指向相反方向 | ⛔ 否决 |

## 质量检查

- [ ] 分产品数据显示新业务/传统业务毛利率差异
- [ ] 任何 GM>90% 的分部已经过交叉验证
- [ ] 质押率已验证（tushare + investoday 双源）
- [ ] OCF 为负的原因已被分析（投入期 vs 烧钱）
- [ ] Numbers vs Narrative 的结论被明确标注
