# 产业分析

改编自 Anthropic `competitive-analysis` (Phase 1-2) + `sector-overview` (Step 1-6)，A 股适配。

## ⚠️ 方法适用性检查

| 方法 | 前置条件 | 不满足时 |
|------|---------|---------|
| **TAM 估算** | 有可引用来源（券商/白皮书/招股书） | ⚠️ 标注「TAM 为管理层指引，未经第三方验证」 |
| **竞争对比** | 存在 ≥3 家可比上市公司 | ⚠️ 标注「可比公司数量有限，竞争分析覆盖不全」 |
| **护城河评级** | 公司上市 >1 年且有公开竞争信息 | ⚠️ 标注「护城河评级基于有限公开信息」 |

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| 用户消息 | 藏经阁预研（产业链节点、行业阶段、投资逻辑、核心评分） | Markdown |
| data-verify 输出 | 股票代码、行业分类、基本财务验证结果 | 内存传递 |
| WebSearch | 券商研报、行业白皮书（TAM 数据） | 搜索摘要 |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| → financial/valuation/decision | 一句话产业逻辑、行业阶段判定、卡位评级（强/中/弱）、TAM 及来源、竞争矩阵表、护城河评级、供需结构 | 结构化表格 + 文本 |

## 执行流程

### 1. 行业定义与 TAM

**行业范围**：这个标的处于什么产业链节点？上游/中游/下游？可替代性如何？

**TAM 估算**（有来源，不拍脑袋）：
- 引用券商研报、行业白皮书、公司招股书的 TAM 数据
- 标注来源、年份、假设
- 格式：「2025 年中国 XXX 市场规模约 XXX 亿，3 年 CAGR XX%（来源：XX 券商 XX 日期）」

**行业阶段判定**：
- 0→1：概念验证期（有技术但无规模化商业收入）
- 1→10：商业化加速期（有收入且在快速增长，渗透率 5-20%）
- 10→N：成熟整合期（行业增速放缓，龙头集中度提升）

### 2. 行业结构

**集中度**：CR3/CR5，龙头份额
**价值分配**：利润沉淀在产业链的哪个环节？用数值说话
**进入壁垒**（四维度评级）：

| 壁垒类型 | 强度 | 证据 |
|---------|------|------|
| 技术/专利 | 高/中/低 | |
| 资本门槛 | 高/中/低 | |
| 客户转换成本 | 高/中/低 | |
| 牌照/监管 | 高/中/低 | |

### 3. 竞争格局

**对标公司列表**（A 股 + 国际可比）：

| 公司 | 代码 | 营收 | 增速 | 毛利率 | ROE | PE | 市值 | 与标的的关系 |
|------|------|------|------|--------|-----|-----|------|------------|

**竞争定位可视化**（选择一种）：
- 2×2 矩阵：选出两个最关键竞争维度做四象限
- 价值链地图：标注每个参与者在价值链中的位置
- 如果竞争者 <5 家，用雷达图；>5 家，用分组表

**护城河评估**（改编自 competitive-analysis Step 9）：

| 护城河类型 | 评级 | 证据 |
|-----------|------|------|
| 技术独占性 | | |
| 客户粘性/转换成本 | | |
| 规模效应 | | |
| 网络效应 | | |
| 品牌/牌照 | | |

### 4. 供需分析

**需求侧**：驱动力（政策、技术、消费、国产替代），持续性（3 年+ 还是短期刺激）
**供给侧**：产能约束、技术门槛、原材料瓶颈
**供需缺口**：方向（供不应求/供过于求）、幅度、持续时间

### 5. 关键趋势

**尾部风**（3-5 个正向驱动力）
**逆风**（2-3 个潜在风险）
**技术颠覆风险**：是否存在替代性技术？
**监管方向**：政策在收紧还是放松？

### 6. 一句话产业逻辑

格式：「[公司] 在 [产业链位置] 拥有 [什么卡位]，受益于 [什么驱动力]，正处于 [什么阶段]。核心验证点是 [什么]。」
