# 数据验证

## 输入

| 来源 | 内容 | 格式 |
|------|------|------|
| 用户消息 | 标的分析上下文：股票代码、定数录公司基座（PE/市值/ROIC/毛利率/营收/净利）、匹配灵光列表、匹配案例列表 | Markdown 文本 |
| config.json | tushare token、investoday token | JSON |

## 输出

| 去向 | 内容 | 格式 |
|------|------|------|
| → 后续 Skill | 验证后的关键数据（PE/市值/毛利率/质押率 采用值）、数据矛盾清单、异常标记及处置结果 | 结构化表格 + 标注 |

## 核心原则

**内部一致性 ≠ 数据正确性。** tushare `bz_profit = bz_sales - bz_cost` 可以通过减法验证，但 `bz_cost` 本身可能是 0——这不是数据一致，是数据缺失。

**年报数据 ≠ 当前状态。** tushare 拉取的最新年报（如 FY2025）可能已经是 5-6 个月前的数据。投资叙事是关于「现在和未来」的——不能用半年前的数据决定「涨价是否已在发生」。必须拉取最新的公司公告、月度经营数据、投资者关系记录来验证当前状态。

**公司官方公告 > 券商研报 > 市场传闻。** 任何投资叙事的核心环节（如「涨价」「订单落地」「客户突破」）必须首先在公司公告中寻找直接证据。公司自己说「售价无明显变化」可以直接推翻所有卖方关于「涨价预期」的分析。不先查公告就接受研报结论，是本 Skill 最严重的失误。

## 执行流程

### 1. 关键数据拉取

```bash
python data_helper.py valuation <code>     # PE/PB/市值 + ROE/毛利率
python data_helper.py segment <code>       # 分产品拆解（含异常自动标记）
python data_helper.py pledge <code>        # 质押（风控铁律）
```

> **质押强制规则**：tushare pledge 返回 `[]` 视为拉取失败，必须立即切 investoday (`investoday-api stock/pledge-details --method POST stockCode=<code> pageSize=5`) 重试。investoday 也 `[]` 才可认定为「无质押」。不得以 tushare `[]` 直接结案。若 investoday 调用失败（非空），走 WebSearch 兜底。每一步切换都必须记录在 step1 文件中。```

### 2. 当前状态验证（强制执行·新增）

**年报有滞后，叙事看当下。** tushare 最新数据是最近一期财报（季报/年报），可能已经是数月前的信息。在「涨价」「订单爆发」「客户突破」等实时性叙事中，财报数据的时效性不足以验证核心假设。

**必须执行的搜索**：

```bash
# 搜索 1：公司最新官方表态（公告/投资者关系记录）
WebSearch "{股票名} 最新公告 售价 价格 产能利用率 收入占比"

# 搜索 2：公司是否在近期公开修正/否定了市场预期
WebSearch "{股票名} 异常波动公告 澄清 说明"

# 搜索 3：核心叙事环节的当前状态
WebSearch "{股票名} {核心产品} 价格 2026年 最新"
```

**穷尽搜索原则（核心方法论）**：

> **负面断言（"数据不存在"/"数据错误"）的证据门槛远高于正面断言。** 第一次搜索无结果 ≠ 数据不存在。第一次发现矛盾 ≠ 数据错误。必须先穷尽所有合理的搜索维度/解释口径，再下结论。

具体执行标准：

| 场景 | 穷尽标准 | 达标条件 |
|------|---------|---------|
| 搜索合同/订单/金额 | 切换至少 3 个**搜索维度**后仍无结果 | 换聚合层级(集团/省/市)、换关键词(集采/招标/中标/框架)、换数据源(招标平台/行业聚合/公司公告) |
| 发现数据矛盾 | 排除至少 3 个**解释口径**后仍矛盾 | 换时间范围(单季vs全年)、换定义范围(产品线vs公司/含税vs不含税/订单vs收入)、换数据源(年报vs季报vs调研纪要) |
| 上游声称的关键数字找不到来源 | 独立推算合理性后再判定 | 如果找不到直接来源，用自己的行业知识推算这个数字是否在合理区间——合理则标注"待L5确认"，不合理则标注"存疑" |

> **失败案例（绿盟科技 300369, 2026-06-12）**：
> - 搜中国移动 3.2 亿集采：只搜了省公司维度，没换集团框架/招标聚合维度 → 违反穷尽标准
> - 发现 GM 72% vs 53.9%：没有检查产品线vs公司的口径差异 → 违反穷尽标准
> - 根因相同：**第一轮搜索结果上直接形成结论，没换维度再来一轮**

**判断标准**：

| 公告表述 | 含义 | 行动 |
|---------|------|------|
| "售价无明显变化" / "基本面未发生重大变化" | 涨价叙事被公司自己否定 | 🔴 叙事不成立，降低 Conviction |
| "售价有所上涨" / "订单饱满" / "产能紧张" | 涨价叙事被公司确认 | 🟢 叙事获得 L5 级支撑 |
| 公司未发布相关公告 | 需等下一次定期报告/经营数据 | ⚠️ 标注「当前状态待验证」，降低 Conviction |

**失败案例（泰和新材 002254, 2026-06-09）**：

流水线花了 2 小时分析「海外缺口→芳纶涨价」的投资逻辑，完成了 6 个步骤。但没有人在第一步查一条最基本的搜索——**公司最近有没有说过现在的售价到底涨没涨？** 2026-06-08 公司发布异常波动公告，明确声明：

- "今年 1-5 月产品售价与上年同期比**没有出现明显变化**"
- "对位芳纶在光纤光缆领域收入占比**不足 10%**"
- "产能利用率尚处于**较低水平**"
- "基本面**未发生重大变化**"

这四条直接推翻了整个投资叙事的核心假设。如果 data-verify 第一步就搜索了公司最新公告，2 小时的流水线可以从一开始就中止。

**教训**：**财报是后视镜，公告是前照灯。先用公告验证叙事的当前状态，再决定值不值得花时间分析历史数据。**

### 4. 异常检测协议

`data_helper.py segment` 输出中的 `ANOMALY` 标记自动触发以下协议：

```
ANOMALY 触发
    ↓
Step A: investoday 合并层面验证
    → investoday-api stock/financial-indicators-profitab ...
    → 对比合并毛利率是否一致
    → 如一致但分产品异常 → tushare 分产品成本分配问题
    ↓
Step B: WebSearch 年报附注
    → 搜索「{股票名} {年份}年报 收入构成 分产品 成本」
    → 确认分产品的业务实质
    ↓
Step C: 标注 + 采用修正值
    → 报告中标注「数据源异常/已交叉验证」
    → 给出修正后的合理估计
```

### 5. 常见异常模式（A 股）

| 异常 | 典型表现 | 原因 | 处置 |
|------|---------|------|------|
| 分产品 GM > 90% | 制造业「其他业务」 | tushare bz_cost=0 或废料收入 | WebSearch 年报附注确认业务实质 |
| PE 跳跃 > 100% | 季度间 PE 异常变化 | 非经常性损益或股本变动 | 查扣非净利润 |
| OCF 剧烈波动 | Q4 OCF 突然跳升/跳水 | A 股年末回款/付款集中 | 看全年而非单季 |

### 6. 定数录纠错清单

定数录可能出错的地方——每次验证时重点检查：

- [ ] 分产品毛利率：是否引用了 tushare 的异常高值？（本川案例）
- [ ] 质押率：定数录经常遗漏此项
- [ ] 营收/利润数据：与 tushare 对照
- [ ] BS 检测器输入：NOPAT、WACC 取值是否合理？
- [ ] Bull 情景假设：毛利率、PE 目标是否基于正确数据？

## 数据源优先级

```
tushare (主) → investoday (备) → WebSearch 年报附注 (兜底)
```

凭证在 `config.json` → `dataSources`。

## 质量检查

- [ ] **【最优先】已搜索公司最新公告/投资者关系记录，确认当前价格/订单/产能利用率状态**（年报数据可能已过期 5-6 个月）
- [ ] **公司最新公告中的「当前状态」（售价/产能/收入占比）与投资叙事的核心假设一致**
- [ ] **【新增】合同/订单验证已执行 L1(集团框架)+L2(省公司)+L3(招标聚合) 三层搜索，缺一不可**
- [ ] **【新增】发现数据差异时已执行口径检查（产品vs公司/含税vs不含税/订单额vs收入确认额），排除后再判定**
- [ ] PE/市值/毛利率的 tushare vs 定数录 对照已完成
- [ ] 所有 ANOMALY 标记已触发交叉验证
- [ ] 质押率已验证
- [ ] 定数录数据异常已在报告中标注
- [ ] 如公司最新公告直接否定叙事的核心假设（如"售价无明显变化"）→ 立即标记为否决依据，不等待后续步骤
