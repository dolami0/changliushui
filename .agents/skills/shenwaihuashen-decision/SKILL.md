# 决策推演 Skill

## 触发条件
- 身外化身决策链的最后一步，必须在 search / data-verify / quant / case-match 完成之后调用
- 用户直接要求"推演这个标的"

## 输入

从主 Agent 汇总前序 skill 的输出：
- data-verify 的结果（数据验证 + 交叉确认）
- search 的结果（最新动态 + 负面信号）
- quant 的结果（量化指标 + 综合评分）
- case-match 的结果（Top 5 匹配案例 + 6 维比对 + 折扣率）
- 用户的额外指令（如有）

## 六步推演框架

### 第一步：产业逻辑验证
回答三个问题：
1. 公司在产业链中占据什么位置？这个位置是利润截留点还是利润过路点？
2. 行业处于什么阶段？0→1（概念验证）/ 1→10（渗透率爆发）/ 10→N（稳态竞争）？
3. 上下游供需关系是否支撑公司增长？

### 第二步：财务体检
检查四个关键信号：
1. 营收增速：是否在加速？增速 vs 行业均值？
2. 毛利率趋势：改善/稳定/恶化？改善是结构性还是周期性？
3. ROIC 水平：是否 >WACC？ROIC 趋势方向？
4. 现金流质量：经营现金流是否支撑扩张？是否需要持续融资？

⚠️ 亏损企业不跳过此步——需要判断亏损原因（研发投入/规模效应未到/商业模式缺陷）。

### 第三步：估值空间测算
1. 当前 PE/PB/PS 在历史分位数的位置（从 data-verify 获取）
2. 参考案例库中同终态案例的 PE 扩张幅度 × 折扣率
3. BS 检测：市场当前定价隐含了什么假设？这个假设合理吗？
   - 如果隐含 g > 5% 且 PE 分位 > 80，大概率已充分定价

### 第四步：催化剂时间表
1. 未来 3-12 个月有哪些可预期的验证节点？
2. 每个催化剂的置信度（硬日期 > 软预期）和潜在影响
3. 如果催化剂密度过低（<2 个/6个月），不确定性大，应降低确信度

### 第五步：风险扫描
1. 致命风险（发生即归零）：技术替代/监管禁令/专利败诉——概率虽低但必须评估
2. 经营风险（影响幅度可控）：竞争加剧/客户流失/产能延期
3. 市场风险（不可控）：宏观周期/政策变化/汇率——不应过度惩罚但需标注
4. 大股东质押/解禁/关联交易检查

### 第六步：综合判断
基于以上五步：
- 产业逻辑成立 + 财务在改善 + 估值有空间 + 催化剂密度足够 → **通过**
- 产业逻辑成立 + 财务待验证 + 估值有空间 → **有条件通过**（明确条件）
- 任一关键维度不成立 → **否决**

## 同时更新追踪

如果决策为"通过"或"有条件通过"，必须同时创建 `memory/tracking/track-{ticker}.json`，填入初始决策数据。

## 注意事项

- 输出报告必须是完整、可独立阅读的——别人拿到这份报告不需要看其他上下文
- 每个表格必须填满，如果数据缺省标注"N/A"并说明原因
- Conviction score 的评判标准：≥80（几乎确定），60-79（大概率），40-59（可能），<40（不确定性大）
- 如果跳过了某个前序 skill（如未执行 search），在报告中标注
