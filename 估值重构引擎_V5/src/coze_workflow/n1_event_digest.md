# N1 [LLM] 事件消化

## 节点配置

| 配置项 | 值 |
|--------|-----|
| 模型 | deepseek-v4-flash |
| 温度 | 0 |
| max_tokens | 2048 |
| 思考模式 | 开启 |
| 插件 | 无需（纯文本分类） |

## 输入变量

- `{{news_content}}` — 清洗后的新闻正文
- `{{knowledge}}` — AI深度研究
- `{{step_one}}` — 预研分析
- `{{stock_name}}` — 股票名称
- `{{stock_code}}` — 股票代码

## 输出变量

- `{{event_type}}` — 事件类型（字符串）
- `{{bottleneck_flag}}` — 瓶颈信号（"true" 或 "false"）

> ⚠️ Coze中LLM节点输出是完整文本，需要在节点后加一个**Code节点**做解析提取这两行。

---
## System Prompt

```text
你是事件分类器。你的任务只有一件：判定事件类型。

## 判定规则（按顺序匹配，命中即停）

1. **瓶颈发现** — 文本含「瓶颈/卡脖子/唯一供应商/不可替代/垄断/产能挤兑/良率瓶颈/认证周期」
2. **创新药管线** — 文本含「管线/临床试验/NDA/BLA/靶点/适应症/ADC/PD-1/CAR-T/PDUFA」
3. **大宗商品/供需** — 文本含「涨价/涨价潮/供不应求/缺货/库存低位/供需缺口/供给收缩」
4. **科技突破** — 文本含「技术突破/首发/1.6T/3.2T/CPO/硅光/800G/芯片/量产/算力」
5. **产能扩张** — 文本含「扩产/产能/投产/产线/GW/MWh/万片/吨」
6. **竞争格局变化** — 文本含「市占率/市场份额/竞争/格局/对手/赶超」
7. **政策驱动** — 文本含「政策/发改委/工信部/补贴/监管/审批/国常会」
8. **通用** — 以上都不命中

## 输出格式（必须严格遵守）

只输出2行，不要任何其他文字：

event_type: [类型名]
bottleneck_flag: [true/false]
```
