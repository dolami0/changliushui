赛博仙门十倍股猎杀系统 · 移动端使用说明

打开网站后自动识别移动设备并跳转至移动版。底部固定五个标签页，点击切换。

定数录 跟踪令 天机峰 风闻入阵 身外化身

1. 定数录

估值报告列表。每张卡片显示股票名称、代码、概率加权 upside、不对称比和交易等级。

  • 排序：顶部可按时间或 upside 排序
  • 点击卡片：进入详情，查看完整估值报告（Agent-0 至 Agent-3 四阶段分析）
  • 详情页：展示基准/乐观/悲观三情景估值、BS 检测结果、路由判决等

2. 跟踪令

主动跟踪的股票清单。每张卡片显示股票名、代码、论点摘要和跟踪状态。

  • 状态标签：跟踪中 或 已暂停
  • 暂停的记录：半透明显示，排在列表底部
  • 点击卡片：进入详情，可查看投资论点、四大支柱、风险清单、退出条件、催化剂日历和价格日志
  • 暂停/恢复：在详情页顶部，点击 ⏸ / ▶ 按钮切换跟踪状态

3. 天机峰

市场事件情报流。按等级 L0-L5 分类，从微澜到道变。

  • 等级颜色：L5 道变（红）、L4 天兆（橙）、L3 雷动（绿）、L2 风起 / L1 微澜 / L0 尘外（灰）
  • 点击卡片：查看事件详情，含摘要、影响分析和相关股票
  • 下拉刷新：在列表顶部下拉即可刷新数据

4. 风闻入阵

手动提交资讯或分析命题，送入估值引擎处理。

  • 在文本框粘贴资讯内容（必填）
  • 可选填股票代码和名称
  • 点击「传讯入阵」提交，系统自动触发 4-Agent 估值重构管线
  • 底部提供输入示例，可一键填入
处理流程：Agent-0 预路由 → Agent-1 数据炼器 → Agent-2 路由判官 → Agent-3 推演裁决

5. 身外化身

AI 投资决策助手。选择一份定数录后，可查看完整报告、组装上下文 prompt，并与 AI 对话推演。

  • 选择定数录：从列表中选择一份估值报告
  • 展符：自动组装 Agent 报告数据为上下文 prompt
  • 复制：将 prompt 复制到剪贴板，可粘贴给其他 AI 工具
  • 对话：在底部输入框直接提问，AI 基于报告数据回答
  • 上下文配置：点击右上角数字按钮，可选择启用/禁用各 Agent 模块
  • 子视图：报告 / 灵光 / 案例 三个子标签切换查看

通用操作

  • 返回：详情页顶部有 ← 返回按钮
  • 下拉刷新：列表页顶部下拉即可刷新数据
  • 底部导航：五个标签随时切换，当前页高亮为绿色
